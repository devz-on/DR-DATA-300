# Darkness Rises Trial data for the tutorial and first two story stages

The Android trial client reads `data-package.json`, downloads the ZIP release asset, checks its SHA-256 digest, and extracts it to its own `PUB/Resource` directory. The game still requires the local fan server described in the development README.

The `v1` release contains 1 ZIP part(s), 346 files, and SHA-256 checksums in `data-package.json`. Archive paths are relative to the Android app’s external-files directory.

This is an unofficial preservation experiment.
